# PyNeurale

PyNeurale combines typed neural data and analysis with native streaming for
closed-loop BCI experiments. Build Center-Out or SSVEP sessions in Python,
connect simulated acquisition or an LSL stream, and record runs in NRF for
inspection and replay preparation. Vendor-specific hardware adapters are
installed separately; see the [device guide](user_guide/device_providers.md).
